PDF信息提取与Excel生成工具 - 使用说明
========================================

一、运行方式
-----------
1. 双击 PDF信息提取工具.exe 启动（无需安装 Python）
2. 确保 default.cfg 与 exe 在同一目录

二、基本流程
-----------
1. 配置提取规则 -> 框选 PDF 区域设置坐标
2. 打开一个或多个 PDF 文件
3. 点击「开始处理」，确认提取结果
4. 点击「生成Excel」导出汇总表

三、处理模式
-----------
- 1 个 PDF：单文件确认窗口
- 2 个及以上：批量确认窗口

四、文件说明
-----------
default.cfg    - 默认提取规则
workspace.json - 工作区自动保存（关闭后不丢数据）
logs/          - 运行日志

五、快捷键
---------
Ctrl+O  打开文件
Ctrl+S  保存配置
Delete  删除选中行

六、常见问题
-----------
提取为空：重新框选坐标
无法导出：确认所有文件已处理；关闭占用中的 Excel

详细说明请参阅 README.md
