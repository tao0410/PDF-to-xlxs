## v2.0 → v2.1 变更

### 方案修订

| 编号 | 变更 | 说明 |
|------|------|------|
| R1 | 表格模式改为锚点定位 | 从 `extract_tables()` 框选整表方案改为**表头关键词 + 行号**的列边界检测方案，配置更简洁，定位更精准 |
| R2 | 模式名统一 | 关键词匹配 `keyword` → `anchor`；表格提取 `table` → `table_column` |
| R3 | UI 简化 | 表格列面板去掉列名映射子表、高级选项折叠面板，改为表头关键词 + 行号两个输入框 |
| R4 | 配置字段变更 | anchor 模式用 `anchor_text`（原 `keyword`）；table_column 模式用 `column_header` + `row_number`（原 `table_region` + `column_mapping`） |

### Bug 修复

| 编号 | 问题 | 修复 | 涉及文件 |
|------|------|------|---------|
| B1 | 单元格跨 15 行物理线时仅提取前 2 行 | `_cluster_words_to_rows()` 改用动态 max center 策略：12pt 续行逐行吸收，16pt 行间自然断裂 | `pdf_extractor.py` |
| B2 | 提取文字含多余空格（如 `TZY15-L.IN- 2025-0019`） | `_clean_text()` 改为去除所有空白字符，不再保留空格 | `pdf_extractor.py` |
