## 重大功能：三种提取模式

v2.0 将提取引擎从单一"坐标框选"升级为支持三种可混合使用的提取模式：

| 模式 | 标识 | 说明 |
|------|------|------|
| 坐标提取 | `coordinate` | 保留原有功能，按框选坐标裁剪提取 |
| 锚点提取 | `anchor` | 新增，搜索关键词后沿指定方向提取邻近文字 |
| 表格列提取 | `table_column` | 新增，按表头关键词+行号精确定位单元格 |

### 核心能力提升

| 指标 | v1.1 | v2.0 |
|------|------|------|
| 批量提取准确率 | 60%-70%（固定坐标，不同 PDF 位置偏移） | 95%+（语义定位，跟随关键词/表格结构） |
| 动态行数表格 | 不支持 | 支持（自动识别所有数据行） |
| 配置方式 | 每个字段逐一框选坐标 | 关键词模式填文字即可，表格模式框选整表 |
| 向后兼容 | — | 旧 `regions` 配置文件无需修改直接可用 |

## 新增功能

| 编号 | 功能 | 涉及文件 |
|------|------|---------|
| F1 | 锚点提取模式（支持右/下/左/上四个方向、可调范围，同一词块智能提取） | `pdf_extractor.py` + `config_dialog.py` |
| F2 | 表格列提取模式（按表头关键词+行号精确定位单元格，列边界自动检测） | `pdf_extractor.py` + `config_dialog.py` |
| F3 | 三种提取模式可混合使用（锚点字段 + 表格列字段共存于同一配置） | `pdf_extractor.py` |
| F4 | 关键词/表头测试预览：PDF 预览窗口支持彩色高亮标注匹配位置 | `pdf_preview_dialog.py` |
| F5 | 配置规则动态参数面板（按提取模式自动切换参数界面） | `config_dialog.py` |
| F6 | 确认对话框支持多行记录展示和编辑 | `single_confirm_dialog.py` + `main_window.py` |

> **修订（2026-06-10）**：表格模式从 `extract_tables()` 框选整表方案改为**表头关键词 + 行号**的锚点定位方案，配置更简洁，定位更精准。

## 数据结构变更

### 配置文件格式（v1 → v2）

```json
// v1（仍兼容）
{ "rule_name": "...", "regions": [{ "name": "...", "x1": 0, "y1": 0, ... }] }

// v2 新增
{ "rule_name": "...", "rules": [
    { "name": "...", "mode": "anchor", "anchor_text": "编号", "direction": "right", "range": 200, ... },
    { "name": "...", "mode": "table_column", "column_header": "更改对象编号", "row_number": 2, ... }
]}
```

### 提取结果结构（v1 → v2）

```python
# v1
result = { "fields": {"编号": "xxx"}, "field_issues": {} }

# v2
result = { "records": [{"编号": "xxx", "零件编号": "A"}, ...], "field_issues": {} }
# records 为列表；当前所有模式均产生单条记录，架构预留多行能力
```

## 全部改动文件清单

| 文件 | v1.1 → v2.0 改动 |
|------|------------------|
| `src/pdf_extractor/config_manager.py` | 重写：schema 改为 `rules` + 三种 `mode`（coordinate/anchor/table_column）；`_validate_config()` 按模式校验必要字段；`_resolve_rules()` 自动转换旧 `regions` 格式 |
| `src/pdf_extractor/pdf_extractor.py` | 重写：主流程 `_extract_all()` 按 mode 分发；新增 `_extract_coordinate()`、`_extract_anchor()`（方向+范围搜索）、`_extract_table_column()`（列边界检测+行号取值）；输出结构从 `fields` 改为 `records` 列表 |
| `src/pdf_extractor/pdf_preview_dialog.py` | 新增 `set_mode()` / `set_keywords()` 方法；`_draw_highlights()` 用 PyMuPDF 半透明矩形标注匹配位置（5 色轮换）；支持 coordinate/anchor/table_column 三种预览模式 |
| `src/pdf_extractor/config_dialog.py` | 重写：左右分栏布局（规则列表 + 动态参数面板）；三种参数面板按 mode 动态显隐；表格列模式简化为表头关键词+行号；锚点/表格列模式均有测试预览按钮 |
| `src/pdf_extractor/main_window.py` | `_handle_single_confirm()` / `_handle_batch_confirm()` 适配 `records` 列表结构；确认对话框支持多行 |
| `src/pdf_extractor/single_confirm_dialog.py` | 从接受单条 `record` 改为接受 `records` 列表；支持多行记录表格展示和逐行编辑；`get_record()` → `get_records()` |
| `src/pdf_extractor/extraction_worker.py` | 无改动（透传结果，PdfExtractor 内部适配） |

## 向后兼容说明

- 旧 `regions` 格式配置文件：`ConfigManager._resolve_rules()` 自动将每个 region 转为 mode=`coordinate` 的 rule，无需修改配置文件
- 旧 `default.cfg`：同样自动兼容
- 提取结果虽改为 `records` 列表，但对于纯坐标/关键词模式（无 table）始终返回一条记录，与 v1 行为一致
- PDF 预览窗口的坐标框选功能完全保留（coordinate 模式）
