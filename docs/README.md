# 📄 产品文档 (docs)

按软件版本组织，更新记录独立存放。

## 📂 目录结构

```
docs/
├── 许愿墙/                        # 💡 需求收集与跟踪（模板 + 待办需求）
├── V1/                          # V1 大版本
│   ├── V1.0/                    # V1.0 初始版本（PRD / UI / 技术架构 / 开发计划）
│   ├── V1.1/                    # V1.1 子版本（需求 + 技术文档）
│   └── V1.2/                    # V1.2 子版本（预留）
├── V2/                          # V2 大版本（需求与实现计划）
└── 更新记录/                     # 所有版本更新日志（v1.1 ~ v2.1）
```

## 🗂️ 约定

| 目录 | 用途 |
|------|------|
| `许愿墙/` | 待评估需求收集、跟踪，采用状态标签管理 |
| `V*/V*.*/` | 各版本需求、技术、设计文档 |
| `更新记录/` | 所有版本的更新日志，按版本号命名 |
| 新版本 | 在 `V*/` 下新建子目录，如 `V2/V2.1/` |
