> **主色调：绿色系 `#15803D`**

## 一、设计系统（Design Token）

### 1.1 配色体系

#### 主色（Wise 绿色系）

| Token | 色值 | 用途 |
|-------|------|------|
| `primary` | `#15803D` | 主操作按钮、选中状态、进度条 |

| `primary-pressed` | `#166534` | 主按钮按下态 |
| `primary-light` | `#DCFCE7` | 选中行背景、统计卡片选中 |
| `primary-lighter` | `#F0FDF4` | 成功横幅背景、单选按钮选中背景 |

#### 辅助色（语义色）

| Token | 色值 | 用途 |

#### 背景色

| `bg-page` | `#F8FAFC` | 页面整体背景（Stripe 浅灰） |

### 1.2 字体层级

基准字体：`"Microsoft YaHei", "微软雅黑", "Segoe UI", sans-serif`

| 层级 | 字号 | 粗细 | 行高 | 用途 |
|------|------|------|------|------|
| H1 | 20px | 700 (Bold) | 30px | 页面主标题 |
| H2 | 16px | 600 (SemiBold) | 26px | 区域标题（Stripe 风格） |
| H3 | 14px | 600 (SemiBold) | 22px | 卡片标题、section-title |
| Body | 14px | 400 (Regular) | 22px | 正文内容、表格数据 |
| Caption | 12px | 400 (Regular) | 18px | 状态文字、辅助说明 |
| Small | 11px | 400 (Regular) | 16px | 占位符、脚注 |

**层级对比策略**（同 Stripe/Wise）：
- 标题 vs 正文：通过 **粗细差异**（Bold/SemiBold vs Regular）+ **颜色深浅**（`#0F172A` vs `#334155`）区分
- 正文 vs 辅助：通过 **颜色深浅**（`#334155` vs `#64748B`）区分
- 同一区域内字号变化不超过 2 级
- 标题留白充足，与正文间距 8-12px

### 1.3 间距系统

基础单位：**4px**（所有间距为 4 的倍数）

| Token | 值 | 用途 |
|-------|------|------|
| `space-1` | 4px | 图标与文字间距 |
| `space-2` | 8px | 按钮内 padding、标签间距 |
| `space-3` | 12px | 输入框内 padding |
| `space-4` | 16px | 元素间距（同级控件） |
| `space-5` | 24px | 卡片内 padding（Stripe 大留白） |
| `space-6` | 32px | 模块间距（卡片之间） |
| `space-8` | 40px | 区域间距（大模块之间） |
| `space-10` | 48px | 页面级间距 |

**间距原则**（Stripe 大留白）：
- 同一功能组内元素间距：`space-3`（12px）~ `space-4`（16px）
- 不同功能组之间间距：`space-6`（32px）~ `space-8`（40px）
- 页面边缘留白：`space-5`（24px）~ `space-6`（32px）
- 卡片内边距：`space-5`（24px）
- 标题与内容间距：12px

### 1.4 圆角系统

| Token | 值 | 用途 |
|-------|------|------|
| `radius-sm` | 6px | 按钮、输入框、标签页 |
| `radius-md` | 10px | 卡片、表格容器 |
| `radius-lg` | 14px | 弹窗窗口 |
| `radius-xl` | 20px | 进度条（全圆角） |
| `radius-full` | 9999px | 状态标签（pill 形） |

### 1.5 阴影系统

| Token | 值 | 用途 |
|-------|------|------|
| `shadow-sm` | `0 1px 2px rgba(0,0,0,0.04)` | 卡片默认、输入框 |
| `shadow-card` | `0 1px 3px rgba(0,0,0,0.06), 0 1px 2px rgba(0,0,0,0.04)` | Stripe 卡片阴影 |
| `shadow-md` | `0 4px 12px rgba(0,0,0,0.06)` | 下拉菜单、卡片悬停 |
| `shadow-lg` | `0 8px 24px rgba(0,0,0,0.08)` | 弹窗、模态框 |
| `shadow-xl` | `0 16px 48px rgba(0,0,0,0.10)` | 全屏配置窗口 |

## 六、设计原则总结

1. **清新专业**（Wise + Stripe 融合）— 绿色主色带来亲和力，白色卡片 + 精致阴影保证专业感
2. **层次分明**（Stripe 卡片层级）— 通过背景色深浅（#F8FAFC → #F9FAFB → #FFFFFF）和阴影层级区分信息
3. **呼吸感充足**（Stripe 大留白）— 卡片间距 32px+，输入框高度 36px，按钮 padding 10px 20px
4. **一致性**（Cycle 极简）— 所有组件遵循统一圆角、间距、交互状态，无多余装饰
5. **可读性**— 文字色层次（标题 #0F172A / 正文 #334155 / 辅助 #64748B），不使用纯黑
6. **渐变精致**（Stripe 风格）— 主按钮使用渐变绿色，进度条渐变填充，增加质感
