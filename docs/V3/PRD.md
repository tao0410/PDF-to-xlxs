# PDF信息提取与Excel生成工具 v2.2 产品需求文档 (PRD)

> **基于 2026/06/22 许愿墙需求整理，共涵盖 10 项优化需求。**

---

## 一、产品概述

**一句话说明**：PDF信息提取与Excel生成工具是一款轻量级 Windows 桌面应用，帮助办公人员从批量 PDF 中可视化框选提取结构化信息并生成 Excel 汇总表。

**解决的问题**：人工从大量 PDF 文档中逐条复制信息到 Excel 效率低、易出错；本工具通过可视化框选配置 + 批量提取 + 内容确认 + 一键导出，将繁琐的手工录入变为半自动流水线操作。

---

## 二、目标用户

| 用户角色 | 典型场景 | 核心诉求 |
|---------|---------|---------|
| 财务/行政人员 | 从发票、合同、报表 PDF 中提取编号、日期、金额等字段 | 操作简单、批量处理、格式自动校验 |
| 档案管理员 | 从扫描件、归档 PDF 中提取元数据并汇总 | 可视化框选、支持多页提取 |
| 项目经理 | 从项目报告、验收单 PDF 中提取关键指标 | 多文件一起确认、灵活编辑 |
| IT 支持/运维 | 为业务人员配置和维护提取规则 | 规则可保存/加载/分享 |

**共同特点**：非技术背景为主，需要 Windows 原生体验、中文界面、离线可用。

## 三、核心功能清单

### P0 — 必须实现（阻塞使用体验）

| 编号 | 功能 | 来源需求 | 说明 |
|------|------|---------|------|
| P0-1 | 处理完成后自动清空已选择文件列表 | 需求一 | 避免重复点击"开始处理"时报错"没有待处理文件" |
| P0-2 | 修复取消按钮使其可中止批量处理 | 需求二 | 大批量 PDF 处理耗时较长，取消按钮必须能实际中止当前处理任务 |
| P0-3 | 重复内容检测与处理弹窗 | 需求三 | 新增信息与已确认内容完全重复时弹窗，提供覆盖/放弃/新增选项 |
| P0-4 | 存在未处理文件时生成 Excel 的提醒 | 需求四 | 点击"生成 Excel"时若存在未处理文件，弹窗提醒并提供继续/退出/处理文件选项 |
| P0-5 | 支持选中部分文件进行提取处理 | 需求五 | 文件列表中行选中指定条目（Shift 连选 / Ctrl 跳选），仅处理选中的文件，完成后自动从列表移除 |
| P0-6 | Excel 生成格式选择弹窗 | 需求六 | 点击"生成 Excel"时弹出选项：加载自定义模板 或 使用系统默认格式 |

### P1 — 应该实现（显著提升易用性）

| 编号 | 功能 | 来源需求 | 说明 |
|------|------|---------|------|
| P1-1 | 配置提取规则窗口支持全屏 | 需求七 | 右上角增加全屏按钮，与主界面行为一致 |
| P1-2 | 配置窗口改为三栏布局 + 实时预览 | 需求八 | 左栏（提取模式）、中栏（参数配置）、右栏（PDF 预览区 + 测试定位按钮）；切换规则时自动预览高亮表头 |
| P1-3 | "加载配置"移至配置窗口左下角 | 需求九 | 从主页面移出；加载后自动覆盖当前规则，规则名称默认取文件名 |
| P1-4 | 取消主页面"保存配置"按钮，统一使用配置窗口内"保存"/"另存为" | 需求九 | "另存为"默认目录为 exe 同目录，默认名称取左上角规则名称 |
| P1-5 | 配置规则支持多选 + 批量删除 | 需求十 | 多选时中栏参数区显示空白 |
| P1-6 | 配置窗口记忆上次使用的规则 | 新增 | 首次进入使用系统默认配置；用户操作后，下次进入默认使用上次退出时的配置 |

### P2 — 可以延后（锦上添花）

| 编号 | 功能 | 说明 |
|------|------|------|
| P2-1 | 文件列表行选中 | 配合 P0-5 的选择处理功能 |
| P2-2 | 最近使用的配置文件列表 | 快速切换常用提取规则 |
| P2-3 | 键盘快捷键支持（全选/反选/删除等） | 提升效率 |

## 四、页面结构

| 页面 | 名称 | 功能说明 | 入口 |
|------|------|---------|------|
| 1 | **主页面** | 文件选择与管理、处理控制、进度展示、已确认内容总表编辑、导出 Excel、打开配置窗口 | 应用启动 |
| 2 | **配置提取规则窗口** | 三栏布局：提取模式选择、参数配置、PDF 实时预览；规则增删改查、加载/保存配置 | 主页面"配置提取规则"按钮 |
| 3 | **单个文件确认弹窗** | 展示单文件提取结果、单元格编辑、确认/重新提取/取消 | 选中 1 个文件处理 |
| 4 | **批量确认弹窗** | 展示多文件提取结果并提供统计、全部确认/重新提取全部/取消 | 选中 ≥2 个文件处理 |
| 5 | **重复内容处理弹窗** | 检测到重复信息时给出覆盖/放弃/新增选项 | 处理完成自动触发 |
| 6 | **Excel 生成选项弹窗** | 选择自定义模板文件或使用系统默认格式 | 主页面"生成 Excel"按钮 |
| 7 | **未处理文件提醒弹窗** | 提醒存在未处理文件，提供继续/退出/处理文件选项 | 主页面"生成 Excel"按钮（有未处理文件时） |

生成 Excel 文件 → 成功提示
    ↓
流程结束
```

### 6.2 提取规则配置流程（v2.2）

```
用户点击"配置提取规则"
    ↓
打开配置窗口（三栏布局）                                        ← 变更
    ↓
┌─────────────────────┐
│ 是否加载已有配置？   │

          │
          ├─ 是 → 点击左下角"加载配置" → 选择 .cfg 文件         ← 位置变更

          │
          └─ 否 → 继续手动配置
          ↓

    ↓

## 七、非功能需求

### 7.1 兼容性
- 保持 Windows 7 SP1 及以上系统兼容
- 保持完全离线运行
- 现有 .cfg 配置文件格式向前兼容

### 7.2 性能
- 配置窗口三栏布局渲染不增加启动时间
- PDF 实时预览切换规则时响应时间 < 500ms
- 重复内容检测不影响批量处理速度

### 7.3 易用性
- 所有新增弹窗提供清晰的中文提示和操作按钮
- 行选中行为与 Windows 文件管理器一致（Shift 连选、Ctrl 跳选）
- 用户误操作可通过弹窗"取消"安全退出

## 八、与 v2.1 的差异总结

| 变更项 | v2.1 行为 | v2.2 行为 |
|--------|----------|----------|
| 文件列表 | 无行选中，处理全部 | 增加行选中（Shift/Ctrl），可按选中处理 |
| 取消按钮 | 存在但无效 | 功能修复，可实际中止批量处理 |
| 处理完成后 | 文件列表保留，再次处理报错 | 自动清空已处理文件 |
| 重复内容 | 静默添加，导致重复 | 弹窗提醒，提供覆盖/放弃/新增 |
| 生成 Excel（有未处理文件时） | 按钮禁用 | 按钮可用，弹窗提醒 |
| 生成 Excel 弹出 | 无选择，直接生成默认格式 | 弹出选项：默认格式/自定义模板 |
| 配置窗口布局 | 左右两栏 | 左中右三栏，支持实时预览 |
| 配置窗口全屏 | 不支持 | 右上角全屏按钮 |
| 加载/保存配置 | 主页面按钮 | 移至配置窗口 |
| 规则多选删除 | 一次只能选一条 | 支持多选批量删除 |
| 配置默认行为 | 无记忆，每次进入用默认配置 | 首次默认配置，后续记忆上次退出配置 |
