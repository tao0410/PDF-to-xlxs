## 技术栈总览

| 类别 | 技术选型 | 说明 |
|------|---------|------|
| 语言 | Python 3.8+ | 目标兼容 Win7 SP1 |
| UI 框架 | PyQt5 | 主窗口 + 所有弹窗 |
| 样式 | QSS（styles.qss） | 全局样式表，参照 UI 设计文档 |
| PDF 处理 | PyMuPDF (fitz) | PDF 解析、页面渲染、文字提取 |
| Excel 生成 | openpyxl | .xlsx 读写，支持模板加载 |
| 打包 | PyInstaller | 单 exe 分发，内嵌资源 |
| 配置存储 | JSON (.cfg) | 提取规则保存/加载 |
| 项目结构 | src/pdf_extractor/ | 主代码目录 |

### 关键文件

```
src/pdf_extractor/
├── main.py                    # 应用入口
├── main_window.py             # 主窗口 UI + 业务逻辑
├── config_dialog.py           # 配置提取规则窗口
├── single_confirm_dialog.py   # 单文件确认弹窗
├── batch_confirm_dialog.py    # 批量确认弹窗
├── pdf_preview_dialog.py      # PDF 预览与框选
├── excel_generator.py         # Excel 生成逻辑
├── pdf_extractor.py           # PDF 提取核心逻辑
├── config_manager.py          # 配置文件读写
├── resources/
│   └── styles.qss             # 全局样式表
└── logs/                      # 日志目录
```

## 步骤 1：UI 样式系统更新

### 目标

将 styles.qss 从微软扁平蓝（#0078D7）更新为绿色系（#15803D），并引入新的组件样式类。

### 涉及文件

- `src/pdf_extractor/resources/styles.qss` — 全局样式表（**重写**）

### 实现内容

1. 替换主色：`#0078D7` → `#15803D`，悬停 `#16A34A`，按下 `#166534`
2. 背景色：`#FFFFFF` → `#F8FAFC`
3. 文字色：`#000000` → `#0F172A`（标题）/ `#334155`（正文）
4. 辅助色：`#666666` → `#64748B`
5. 表格选中行：`#CCE4FF` → `#DCFCE7`
6. 表头背景：`#E5F3FF` → `#F8FAFC`
7. 圆角：按钮 `2px` → `6px`，卡片 `8px` → `10px`
8. 按钮 padding：`6px 16px` → `10px 20px`
9. 输入框高度：32px → 36px
10. 进度条高度：6px → 8px
11. 新增 class：`card`、`warning-banner`、`success-banner`、`danger-banner`、`ghost`、`sidebar`、`status-tag`、`section-title`

### 验证标准

- [ ] 启动应用后主界面背景色为 `#F8FAFC`
- [ ] 所有按钮为绿色渐变，圆角 6px
- [ ] 输入框高度 36px，聚焦边框为绿色
- [ ] 进度条为绿色渐变填充，高度 8px
- [ ] 所有新增 class 在 QSS 中有定义

### 验证标准

## 步骤 3：主页面 — 处理控制与取消

### 目标

修复取消按钮使其可中止批量处理；处理完成后自动清空已处理文件。

### 涉及文件

- `src/pdf_extractor/main_window.py` — 主窗口（**修改**）

### 实现内容

1. "开始处理"按钮逻辑：仅处理勾选的文件（未勾选则跳过）
2. 进度条实时更新（当前文件序号 / 总选中文件数）
3. 状态文字显示"正在处理：xxx.pdf"
4. "取消"按钮：调用提取器的 `cancel()` 方法，中止当前任务
5. 取消后恢复按钮状态，已处理的文件结果保留
6. 处理完成后：自动从文件列表移除已处理的文件
7. 处理完成后：更新底部统计（"共 N 个，已处理 X 个，待处理 Y 个"）

### 验证标准

- [ ] 勾选 3 个文件中的 2 个，点击"开始处理"，仅处理这 2 个
- [ ] 处理过程中点击"取消"，任务中止，已处理结果保留
- [ ] 处理完成后，已处理文件自动从列表移除
- [ ] 进度条实时更新，状态文字显示当前文件名
- [ ] 取消后按钮恢复可点击状态

## 步骤 7：重复内容检测弹窗

### 目标

新提取内容与已确认内容完全重复时弹窗提醒，提供覆盖/放弃/新增选项。

### 涉及文件

- `src/pdf_extractor/main_window.py` — 主窗口（**修改**）
- `src/pdf_extractor/repeat_dialog.py` — 重复内容弹窗（**新建**）

### 实现内容

1. 新建 `RepeatDialog` 类（继承 `QDialog`）
2. 弹窗标题："重复内容检测"
3. 警告提示："⚠ 检测到以下内容与已确认内容完全重复"
4. 表格展示重复的记录
5. 三个单选项（Radio Button）：覆盖、放弃、新增，每项有标题和描述

- [ ] 选择"新增"后，重复内容作为新行添加（允许重复）

## 步骤 10：配置窗口 — 三栏布局重构

### 目标

配置提取规则窗口从左右两栏改为三栏布局：左栏（提取规则表格）、中栏（坐标参数）、右栏（PDF 预览）。

### 涉及文件

- `src/pdf_extractor/config_dialog.py` — 配置窗口（**重写布局**）

### 实现内容

1. 窗口标题栏新增全屏按钮（右上角）
2. 规则名称输入行：输入框 + "重命名"按钮
3. 左栏（提取规则表格）：
   - 四列表格：字段、模式（下拉框）、页面范围、数据类型（下拉框）

## 步骤 11：配置窗口 — 全屏 + 加载/保存 + 规则排序

### 目标

配置窗口支持全屏；加载/保存配置移至窗口内；支持上移/下移调整规则顺序及多选批量删除。

### 涉及文件

- `src/pdf_extractor/config_dialog.py` — 配置窗口（**修改**）
- `src/pdf_extractor/config_manager.py` — 配置管理（**修改**）

### 实现内容

1. 全屏按钮：右上角新增全屏/还原按钮，与主界面行为一致
2. 底部操作栏：
   - 左下角："加载配置"按钮
   - 右下角："保存"、"另存为"、"关闭"按钮
3. "加载配置"：弹出文件选择对话框，选择 .cfg 文件
   - 加载后自动覆盖当前规则
   - 规则名称默认取配置文件的文件名（不含扩展名）
4. "保存"：保存当前配置到已加载的文件路径
5. "另存为"：弹出保存对话框
   - 默认目录：exe 同目录
   - 默认名称：左上角规则名称
   - 保存为 .cfg 文件
6. 规则排序与批量删除：
   - "上移"/"下移"按钮：调整选中行顺序
   - "删除"按钮：删除选中的规则行（支持多选批量删除）
   - 多选时中栏显示空白

### 验证标准

- [ ] 点击全屏按钮，配置窗口全屏显示；再次点击还原
- [ ] "加载配置"在窗口左下角，点击可选择 .cfg 文件
- [ ] 加载配置后，规则名称自动取文件名
- [ ] "另存为"默认目录为 exe 同目录，默认名称为规则名称

## 步骤 12：配置记忆与兼容性

### 目标

配置窗口记忆上次使用的规则；确保 .cfg 文件向前兼容。

### 涉及文件

- `src/pdf_extractor/config_manager.py` — 配置管理（**修改**）
- `src/pdf_extractor/config_dialog.py` — 配置窗口（**修改**）

### 实现内容

1. 配置记忆：
   - 首次打开配置窗口：使用系统默认配置（default.cfg）
   - 用户修改配置后关闭窗口：自动保存当前配置到临时文件（last_config.cfg）
   - 下次打开配置窗口：自动加载 last_config.cfg
2. .cfg 向前兼容：
   - v2.1 的 .cfg 文件在 v2.2 中可正常加载
   - 新增字段（如模式列）在旧配置中缺失时使用默认值
3. 配置文件格式：JSON，包含规则名称、规则列表（字段/模式/页面范围/数据类型/坐标）

### 验证标准

- [ ] 首次打开配置窗口，显示系统默认配置

- [ ] 保存的 .cfg 文件可在 v2.2 中正常加载
