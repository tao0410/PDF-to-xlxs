# PDF 提取工具 v2.0 — 需求文档 & 实现计划（修订版）

> **修订日期**：2026-06-10 | **修订原因**：表格提取方案从 `extract_tables()` 框选整表 → 改为表头关键词 + 列边界检测 + 指定行号

## 一、需求概述

三种提取模式可混合使用，每个字段独立选择模式：

| 模式 | 标识 | 适用场景 | 配置方式 |
|------|------|---------|---------|
| 坐标提取 | `coordinate` | 排版完全固定的 PDF | 框选矩形区域（保留 v1 功能） |
| 锚点提取 | `anchor` | 键值对表单头部 | 填标签关键词 + 取值方向 |
| 表格列提取 | `table_column` | 表格中指定行/列的数据 | 填表头关键词 + 行号 |

## 二、已对齐的关键决策

| # | 决策项 | 结论 |
|---|--------|------|
| 1 | 三种模式共存 | coordinate / anchor / table_column |
| 2 | 配置命名 | 顶层 `rules`，数据类型用中文 |
| 3 | 预览窗口模式区分 | 增加模式标记 |
| 4 | 关键词高亮 | 需要，测试 PDF 时半透明标注 |
| 5 | 表格列取值方式 | **严格行号**，仅取指定行 |
| 6 | 行号语义 | `row_number=2` = 表头下方第一条数据行 |
| 7 | 续行合并 | **不做**自动合并，严格按行号提取 |
| 8 | 输出结构 | records 列表（架构预留多行，当前每条规则产生单值） |

## 三、提取模式详细规格

### 3.1 坐标提取（coordinate）

完全保留 v1 逻辑不变：
- 配置：`x1, y1, x2, y2, page_range`
- 算法：`page.within_bbox()` → `extract_text()` → `_clean_text()`

### 3.2 锚点提取（anchor）

**配置参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `anchor_text` | string | 必填 | 搜索关键词，包含匹配（如"编号"匹配"编号：xxx"） |
| `direction` | enum | `right` | 取值方向：`right` / `below` / `left` / `above` |
| `range` | int | `200` | 搜索范围（像素） |
| `page_range` | string | `第1页` | 页码范围 |

**算法**：
1. `page.extract_words()` 搜索 text 包含 `anchor_text` 的词块
2. 尝试同一词块内提取：去标签去冒号 → 返回剩余文字
3. 词块内无值则按 `direction` + `range` 搜索邻近词块并拼接
4. 未匹配返回空 + issue

### 3.3 表格列提取（table_column）

**配置参数**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `column_header` | string | 必填 | 表格列标题关键词 |
| `row_number` | int | `2` | 行号：1=表头行，2=第一条数据行，3=第二条… |
| `page_range` | string | `第1页` | 页码范围 |

**算法**：
1. 搜索包含 `column_header` 的词块（优先匹配多列表头行，跳过孤立章节标题）
2. 收集该词块所在 Y 行的所有词块 → 按 X 排序 → 相邻列中点分割 → 确定目标列 X 范围
3. 表头以下词块按 Y 聚类成行（容差 ±12pt）
4. 按 `row_number` 取数据行索引（row_number - 2 = 数据行数组索引）
5. 取该行中 X 落在目标列范围的词块拼接
6. 未匹配返回空 + issue

## 四、配置文件格式

```json
{
  "rule_name": "ECO工程更改单提取规则",
  "rules": [
    {
      "name": "编号",
      "mode": "anchor",
      "anchor_text": "编号",
      "direction": "right",
      "range": 200,
      "page_range": "第1页",
      "data_type": "文本"
    },
    {
      "name": "产品型号",
      "mode": "anchor",
      "anchor_text": "产品型号",
      "direction": "right",
      "range": 200,
      "page_range": "第1页",
      "data_type": "文本"
    },
    {
      "name": "零件编号",
      "mode": "table_column",
      "column_header": "更改对象编号",
      "row_number": 2,
      "page_range": "第1页",
      "data_type": "文本"
    },
    {
      "name": "更改描述",
      "mode": "table_column",
      "column_header": "更改内容",
      "row_number": 2,
      "page_range": "第1页",
      "data_type": "文本"
    }
  ]
}
```

### 旧格式兼容

旧 `regions` 格式自动映射：每项 mode=`coordinate`，`data_type` 从原字段读取，无需修改。

## 五、数据流

```
PdfExtractor.extract_single() → {records: [{name: value}], field_issues: {}}
                                     ↓
ExtractionWorker → 透传 result
                                     ↓
MainWindow → 展平 records → 确认对话框 → content table
```

当前 anchor 和 table_column 均返回单值，故 records 数组长度 = 1。架构预留多行能力。

## 六、UI 变更

### 6.1 config_dialog.py

**布局**：左侧规则列表 + 右侧动态参数面板

**动态参数面板**按模式切换：

| 模式 | 显示内容 |
|------|---------|
| 坐标提取 | X1/Y1/X2/Y2 + 页面范围 + 数据类型 + "选择PDF预览并框选" |
| 锚点提取 | 关键词 + 方向(下拉) + 范围(数字) + 页面范围 + 数据类型 + "测试关键词" |
| 表格列提取 | 表头关键词 + 行号(数字) + 页面范围 + 数据类型 + "测试定位" |

- "测试关键词"按钮：打开 PDF 预览（anchor 模式），彩色高亮所有锚点规则的关键词
- "测试定位"按钮：打开 PDF 预览（table_column 模式），高亮当前规则的表头关键词位置

### 6.2 pdf_preview_dialog.py

保留框选功能（coordinate 模式）。新增：

- `set_mode("anchor")`：关键词彩色高亮
- `set_mode("table_column")`：表头关键词高亮
- 高亮实现：PyMuPDF `page.search_for()` + `page.draw_rect()` 半透明覆盖
