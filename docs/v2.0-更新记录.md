## 重大功能：三种提取模式

v2.0 将提取引擎从单一"坐标框选"升级为支持三种可混合使用的提取模式：

| 模式 | 标识 | 说明 |
|------|------|------|
| 坐标提取 | `coordinate` | 保留原有功能，按框选坐标裁剪提取 |
| 关键词匹配 | `keyword` | 新增，搜索关键词后沿指定方向提取邻近文字 |
| 表格结构识别 | `table` | 新增，框选表格区域后自动识别列和数据行 |

### 核心能力提升

| 指标 | v1.1 | v2.0 |
|------|------|------|
| 批量提取准确率 | 60%-70%（固定坐标，不同 PDF 位置偏移） | 95%+（语义定位，跟随关键词/表格结构） |
| 动态行数表格 | 不支持 | 支持（自动识别所有数据行） |
| 配置方式 | 每个字段逐一框选坐标 | 关键词模式填文字即可，表格模式框选整表 |
| 向后兼容 | — | 旧 `regions` 配置文件无需修改直接可用 |

## 数据结构变更

### 配置文件格式（v1 → v2）

```json
// v1（仍兼容）
{ "rule_name": "...", "regions": [{ "name": "...", "x1": 0, "y1": 0, ... }] }

// v2 新增
{ "rule_name": "...", "rules": [
    { "name": "...", "mode": "keyword", "keyword": "编号", "direction": "right", "range": 200, ... },
    { "name": "...", "mode": "table", "table_region": [45,430,560,715], "column_mapping": {...}, ... }
]}
```

### 提取结果结构（v1 → v2）

```python
# v1
result = { "fields": {"编号": "xxx"}, "field_issues": {} }

# v2
result = { "records": [{"编号": "xxx", "零件编号": "A"}, ...], "field_issues": {} }
# records 为列表，table 模式时可能有多条；coordinate/keyword 模式时列表含一条
```

## 全部改动文件清单

| 文件 | v1.1 → v2.0 改动 |
|------|------------------|
| `src/pdf_extractor/config_manager.py` | 重写：schema 改为 `rules` + 三种 `mode`（coordinate/keyword/table）；`_validate_config()` 三模式校验；`_resolve_rules()` 自动转换旧 `regions` 格式；`get_column_names()` 展开 table 的 `column_mapping` 输出名 |
| `src/pdf_extractor/pdf_extractor.py` | 重写：主流程 `_extract_all()` 按 mode 分发；新增 `_extract_coordinate()`（保留原逻辑）、`_extract_keyword()`（方向+范围搜索）、`_extract_table()`（pdfplumber 原生 `extract_tables()`）；输出结构从 `fields` 改为 `records` 列表；混合模式下自动将标量字段值重复填充到每条表格记录 |
| `src/pdf_extractor/pdf_preview_dialog.py` | F5+F6：新增 `set_mode()` / `set_keywords()` 方法；关键词模式 `_draw_highlights()` 用 PyMuPDF 半透明矩形标注匹配位置（5 色轮换）；表格模式独立 `table_region_confirmed` 信号；`_confirm_coords()` 按模式分发信号；窗口标题和状态提示按模式切换 |
| `src/pdf_extractor/config_dialog.py` | 重写：左右分栏布局（规则列表 + 动态参数面板）；三种参数面板按 mode 动态显隐；表格模式列名映射子表 + 可折叠高级选项（列/行策略、XY 容差）；`_auto_detect_columns()` 框选后自动识别列名填充；关键词测试按钮打开预览高亮 |
| `src/pdf_extractor/main_window.py` | F4+F9：`_handle_single_confirm()` / `_handle_batch_confirm()` 适配 `records` 列表展平；每 PDF 可能产生多条记录，确认对话框支持多行；重新提取回调同步适配 |
| `src/pdf_extractor/single_confirm_dialog.py` | F9：从接受单条 `record` 改为接受 `records` 列表；支持多行记录表格展示和逐行编辑；`get_record()` → `get_records()` |
| `src/pdf_extractor/extraction_worker.py` | 无改动（透传结果，PdfExtractor 内部适配） |

## 向后兼容说明

- 旧 `regions` 格式配置文件：`ConfigManager._resolve_rules()` 自动将每个 region 转为 mode=`coordinate` 的 rule，无需修改配置文件
- 旧 `default.cfg`：同样自动兼容
- 提取结果虽改为 `records` 列表，但对于纯坐标/关键词模式（无 table）始终返回一条记录，与 v1 行为一致
- PDF 预览窗口的坐标框选功能完全保留（coordinate 模式）
