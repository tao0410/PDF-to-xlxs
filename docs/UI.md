# PDF信息提取与Excel生成工具 完整产品文档(PRD)
## 1. 产品概述
### 1.1 产品名称
PDF信息提取与Excel生成工具

### 1.2 产品定位
一款轻量级、纯本地运行的Windows桌面应用，专为需要从大量PDF文档中提取结构化信息并整理成Excel表格的办公人员设计。通过可视化框选配置提取规则，支持单文件逐个确认和多文件批量处理两种模式，大幅提高信息整理效率，减少人工录入错误。

### 1.3 产品目标
- 开发一个**完全离线运行**的应用，不依赖任何网络连接或云服务
- 严格兼容**Windows 7 SP1 32位/64位**系统
- 提供**可视化框选**功能，无需手动输入坐标即可配置提取规则
- 支持两种处理模式：单文件逐个确认和多文件批量确认
- 自动按编号排序生成标准Excel文件
- 生成单个可执行exe文件，无需安装额外运行环境

### 1.4 核心流程
```
用户选择PDF文件 → 配置提取规则(可视化框选) → 点击"开始处理"
├─ 若选择1个PDF → 提取内容 → 弹出单个文件确认窗口 → 用户确认/编辑 → 内容存入总列表
└─ 若选择≥2个PDF → 批量提取所有文件内容 → 弹出统一确认窗口展示所有内容 → 用户确认/编辑 → 内容存入总列表
→ 用户在主界面总编辑窗口做最终调整 → 点击"生成Excel" → 生成按编号排序的Excel文件
```

## 2. 运行环境要求
| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 7 SP1 及以上版本（32位/64位） |
| 运行依赖 | 无需安装.NET Framework、Java等额外运行环境 |
| 网络要求 | 完全离线运行，不依赖任何网络连接 |
| 硬件要求 | 最低配置：2GB内存，1GHz处理器，100MB可用磁盘空间 |
| 兼容性 | 支持PDF 1.4及以上版本，兼容Microsoft Excel 2007及以上版本生成的.xlsx文件 |

## 3. 功能需求
### 3.1 主界面功能
#### 3.1.1 文件选择功能
- 点击"打开"按钮，弹出标准Windows文件选择对话框
- 文件过滤器默认只显示PDF文件(*.pdf)
- 支持同时选择多个PDF文件（按住Ctrl或Shift键多选）
- 支持从文件资源管理器拖拽PDF文件到主界面添加
- 显示已选择文件的列表，包含：序号、文件名、文件大小、处理状态（待处理/处理中/已确认/已跳过）
- 支持移除单个已选择的文件
- 支持清空所有已选择的文件
- 支持重复添加文件，自动检测并提示重复文件
- 显示已选择文件的总数、已处理数和待处理数

#### 3.1.2 处理控制功能
- **"开始处理"按钮**：点击后开始提取所有已选择的PDF文件内容
- 处理过程中显示整体进度条和当前正在处理的文件名
- 处理过程中可随时点击"取消"按钮终止操作
- 单个PDF提取失败时，弹出错误提示，用户可选择"跳过该文件"或"取消全部处理"

#### 3.1.3 生成Excel功能
- 只有当所有文件都处理完成（已确认或已跳过）后，"生成Excel"按钮才可用
- 点击"生成Excel"按钮，将总编辑列表中的所有内容按编号升序排序并生成Excel文件
- 生成完成后弹出成功提示，并显示生成的Excel文件路径
- 提供"打开文件"和"打开文件夹"快捷按钮

#### 3.1.4 总内容编辑功能
- 主界面下方显示总内容编辑表格，实时展示所有已确认的内容
- 表格列对应配置的提取区域，增加"来源文件"列
- 支持直接在表格中编辑任何单元格的内容
- 支持添加新的记录行
- 支持删除不需要的记录行
- 支持复制、粘贴单元格内容
- 支持批量选择多行进行删除操作
- 显示总记录数

### 3.2 提取规则配置功能
#### 3.2.1 基础配置功能
- 支持配置多个提取区域，每个区域包含：
  - 区域名称（如"编号"、"名称"、"日期"、"金额"等）
  - 页面范围（如"第1页"、"第2-5页"、"所有页"）
  - 左上角X/Y坐标
  - 右下角X/Y坐标
  - 数据类型（文本、数字、日期）
- 提取规则可以保存为*.cfg配置文件
- 支持加载已保存的配置文件
- 提供默认配置模板
- 支持添加、删除、上移、下移提取规则行

#### 3.2.2 可视化框选功能（核心新增）
- 在配置窗口添加"**选择PDF预览并框选**"按钮
- 点击按钮弹出标准文件选择对话框，选择任意PDF文件用于预览
- 打开独立的PDF预览与框选窗口
- 支持PDF预览窗口的翻页功能（上一页/下一页/页码显示）
- 支持PDF预览窗口的缩放功能（放大/缩小/适应窗口/实际大小）
- 用户可使用鼠标在PDF预览区域拖拽绘制矩形框
- 框选过程中实时显示鼠标坐标和框选区域坐标
- 框选完成后点击"确认坐标"，自动将该区域的左上角X/Y坐标、右下角X/Y坐标和当前页码填充到配置窗口中**选中的提取规则行**
- 支持清除当前框选，重新绘制
- 关闭PDF预览窗口不影响已填写的配置内容
- 未选中任何提取规则行就点击框选按钮时，提示"请先选择要配置的提取规则行"

### 3.3 内容确认与编辑功能
#### 3.3.1 单个文件确认窗口（单文件模式）
- 当用户只选择1个PDF文件时，提取完成后立即弹出
- 窗口标题显示当前处理的文件名
- 以表格形式展示该文件提取的所有内容
- 表格列对应配置的提取区域
- 高亮显示可能有问题的内容（如格式错误、内容为空、提取失败）
- 支持直接在表格中编辑任何单元格的内容
- 提供三个操作按钮：
  - **"确认"**：保存当前内容到总编辑列表，关闭确认窗口
  - **"重新提取"**：使用相同配置重新提取当前PDF文件
  - **"取消"**：不保存当前内容，关闭确认窗口

#### 3.3.2 统一确认窗口（多文件模式）
- 当用户选择≥2个PDF文件时，全部提取完成后立即弹出
- 窗口标题显示"批量确认提取内容"
- 以表格形式展示所有PDF文件提取的全部内容
- 表格列对应配置的提取区域，增加"来源文件"列
- 高亮显示可能有问题的内容（如格式错误、内容为空、提取失败）
- 支持直接在表格中编辑任何单元格的内容
- 支持添加新的记录行
- 支持删除不需要的记录行
- 支持批量选择多行进行删除操作
- 提供三个操作按钮：
  - **"全部确认"**：保存表格中所有内容到总编辑列表，关闭确认窗口
  - **"重新提取全部"**：使用相同配置重新提取所有PDF文件
  - **"取消"**：不保存任何内容，关闭确认窗口

### 3.4 Excel生成功能
- 自动按照"编号"列对所有已确认的记录进行升序排序
- 生成标准的.xlsx格式文件
- Excel文件包含与总编辑窗口相同的列标题（包括"来源文件"列）
- 自动调整列宽以适应内容
- 为表头添加背景色和加粗效果
- 支持设置生成文件的保存路径和文件名
- 默认文件名格式："PDF信息汇总表_YYYYMMDD_HHMMSS.xlsx"

### 3.5 辅助功能
#### 3.5.1 日志功能
- 记录所有操作日志，包括文件添加、移除、提取、确认、生成等
- 详细记录每个PDF文件的处理时间和结果
- 记录错误和异常信息
- 日志文件保存在应用程序目录下的logs文件夹中
- 日志文件按日期命名，自动保留最近30天的日志

#### 3.5.2 异常处理
- 选择非PDF文件时，弹出错误提示
- 打开损坏的PDF文件时，弹出错误提示
- 提取区域超出PDF页面范围时，自动修正为页面边界坐标
- 磁盘空间不足时，弹出错误提示
- 生成的Excel文件正在被其他程序打开时，弹出错误提示

## 4. 非功能需求
### 4.1 性能要求
- 单个PDF文件提取时间不超过2秒
- 批量处理100个PDF文件的总时间不超过5分钟
- 应用程序启动时间不超过3秒
- 内存占用不超过200MB

### 4.2 可用性要求
- 界面简洁直观，用户无需培训即可上手使用
- 所有操作都有明确的反馈
- 错误提示清晰易懂，提供解决方案
- 支持键盘快捷键操作

### 4.3 可靠性要求
- 应用程序崩溃率低于0.1%
- 数据不丢失：已确认的内容在应用程序关闭后不会丢失
- 支持断点续处理：应用程序关闭后重新打开，可以继续之前的处理

# PDF信息提取与Excel生成工具 完整UI设计文档
## 1. 设计概述
### 1.1 设计目标
基于产品需求文档，设计一套符合**Windows 7原生风格**、简洁易用、功能明确的桌面应用界面。确保界面在Windows 7系统上显示正常，交互逻辑清晰，用户能够快速上手完成PDF信息提取和Excel生成的核心任务。

### 1.2 设计原则
- **原生一致性**：严格遵循Windows 7桌面应用设计规范，使用系统原生控件和交互方式
- **功能优先**：突出核心功能按钮和操作区域，减少不必要的视觉元素

## 5. 交互流程设计
### 5.1 提取规则配置流程
1. 用户点击主界面"配置提取规则"按钮
2. 打开提取规则配置窗口
3. 用户选择要配置的提取规则行
4. 用户点击"选择PDF预览并框选"按钮
5. 选择一个PDF文件用于预览
6. 打开PDF预览与框选窗口
7. 用户翻页到需要提取的页面
8. 用户使用鼠标拖拽绘制矩形框选择提取区域
9. 实时显示坐标信息
10. 用户点击"确认坐标"按钮
11. 坐标和页码自动填充到配置窗口的选中行
12. 用户可以继续配置其他提取区域
13. 配置完成后点击"保存"按钮保存配置

### 5.2 单文件处理流程
1. 用户点击"打开"按钮，选择1个PDF文件
2. 文件添加到主界面文件列表
3. 用户点击"开始处理"按钮
4. 应用提取PDF内容
5. 弹出单个文件确认窗口，展示提取结果
6. 用户检查并编辑内容
7. 用户点击"确认"按钮
8. 内容添加到主界面已确认内容表格
9. "生成Excel"按钮变为可用
10. 用户点击"生成Excel"按钮
11. 应用按编号排序并生成Excel文件
12. 弹出成功提示，提供打开文件和文件夹选项

### 5.3 多文件处理流程
1. 用户点击"打开"按钮，选择≥2个PDF文件
2. 文件添加到主界面文件列表
3. 用户点击"开始处理"按钮
4. 应用批量提取所有PDF内容
5. 弹出批量确认窗口，展示所有提取结果
6. 用户检查并编辑内容
7. 用户点击"全部确认"按钮
8. 所有内容添加到主界面已确认内容表格
9. "生成Excel"按钮变为可用
10. 用户点击"生成Excel"按钮
11. 应用按编号排序并生成Excel文件
12. 弹出成功提示，提供打开文件和文件夹选项

## 6. 技术实现指导
### 6.1 推荐组件
| 功能模块 | 推荐PyQt5组件 |
|---------|--------------|
| 主窗口 | QMainWindow |
| 文件选择 | QFileDialog |

| 对话框 | QDialog |

| 下拉框 | QComboBox |
| 消息提示 | QMessageBox |
| PDF预览 | QLabel + QScrollArea |
| 框选效果 | QRubberBand |
| 工具栏 | QToolBar |
| 状态栏 | QStatusBar |

### 6.2 关键实现要点
1. **坐标系统统一**：使用PDF原生坐标系统（原点在左下角），确保PyMuPDF和pdfplumber坐标一致
2. **多线程处理**：将PDF提取操作放在后台线程中执行，避免界面卡顿
3. **异常处理**：在所有可能出错的地方添加try-except块，显示友好的错误提示
4. **中文支持**：确保所有中文显示正常，使用UTF-8编码
5. **样式统一**：使用Qt样式表(QSS)统一设置所有控件的样式
