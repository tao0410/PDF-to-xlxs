#### 2. 逻辑层 — 清空方法

新增方法 `_clear_all_records()`：

```python
def _clear_all_records(self):
    """一键清空全部已确认内容。"""
    if not self.confirmed_records:
        return
    count = len(self.confirmed_records)
    reply = QMessageBox.question(
        self, "确认清空",
        f"确定清空全部已确认内容？（共 {count} 条记录）"
    )
    if reply == QMessageBox.Yes:
        self.confirmed_records.clear()
        self._refresh_content_table()
        self._update_ui_state()
        self._save_session()
```

#### 3. 状态联动 — 更新 `_update_ui_state()`

```python
def _update_ui_state(self):
    # ... 现有逻辑 ...
    self.btn_clear_records.setEnabled(len(self.confirmed_records) > 0)  # 新增
```

### 技术要点

- 仅在 `confirmed_records` 非空时按钮可用
- 清空前二次确认，避免误操作
- 清空后同步刷新 UI 和会话持久化

## 功能二：Excel 导出成功后自动清空

### 改动文件

[main_window.py](src/pdf_extractor/main_window.py)

### 实现方案

修改 `_export_excel()` 方法。当前逻辑为导出成功后弹出三选一对话框。修改为：当用户点击「关闭」时，执行清空操作。

```python
def _export_excel(self):
    # ... 前面保持不变（校验、选择路径、生成 Excel）...

    if gen.generate(records, path):
        msg = QMessageBox(self)
        msg.setWindowTitle("成功")
        msg.setText(f"Excel 文件已生成：\n{path}")
        btn_open = msg.addButton("打开文件", QMessageBox.ActionRole)
        btn_folder = msg.addButton("打开文件夹", QMessageBox.ActionRole)
        btn_close = msg.addButton("关闭", QMessageBox.RejectRole)
        msg.exec_()
        clicked = msg.clickedButton()
        if clicked == btn_open:
            os.startfile(path)
        elif clicked == btn_folder:
            os.startfile(os.path.dirname(path))
        elif clicked == btn_close:
            # 新增：自动清空文件列表和已确认内容
            self.files.clear()
            self.confirmed_records.clear()
            self._refresh_file_table()
            self._refresh_content_table()
            self._update_ui_state()
            self._save_session()
        logger.info("Excel 导出成功: %s", path)
```

### 技术要点

- 仅在成功导出 + 用户点击「关闭」时触发
- 若用户点击「打开文件」或「打开文件夹」，不执行清空（用户可能还需查看文件后再手动清空）
- 清空范围：文件列表 `self.files` + 已确认内容 `self.confirmed_records`，两处同步
- 清空后会话保存，下次启动不会恢复已清空数据

## 功能三：配置规则时可多次框选（同一 PDF 不重复打开）

### 改动文件

- [pdf_preview_dialog.py](src/pdf_extractor/pdf_preview_dialog.py)
- [config_dialog.py](src/pdf_extractor/config_dialog.py)

### 设计思路

将 PDF 预览窗口设计为**可复用模态窗口**：

- 预览窗口由 `ConfigDialog` 持有引用，打开一次后保持存活
- 「确认坐标」不再关闭窗口，仅发射信号 + 显示简短状态提示
- 坐标每次填充到**当前选中行**，而非打开窗口时的固定行
- 点击「关闭」或窗口关闭时才销毁

### 实现方案

#### 3.1 `pdf_preview_dialog.py` 修改

##### 3.1.1 修改 `_confirm_coords()` (L274-282)

**当前代码：**
```python
def _confirm_coords(self):
    x1, y1, x2, y2 = self._pdf_bbox
    if x1 == x2 and y1 == y2:
        QMessageBox.warning(self, "提示", "请先框选提取区域")
        return
    page_num = self._current_page + 1
    self.coordinates_confirmed.emit(x1, y1, x2, y2, page_num)
    QMessageBox.information(self, "成功", "坐标已确认，将填充到选中的提取规则行")
    self.accept()  # ← 删除此行，窗口不再自动关闭
```

**修改后：**
```python
def _confirm_coords(self):
    x1, y1, x2, y2 = self._pdf_bbox
    if x1 == x2 and y1 == y2:
        QMessageBox.warning(self, "提示", "请先框选提取区域")
        return
    page_num = self._current_page + 1
    self.coordinates_confirmed.emit(x1, y1, x2, y2, page_num)
    # 不关闭窗口，仅清除框选便于下一次框选
    self._clear_selection()
```

改动说明：
- 删除 `self.accept()` — 窗口保持打开
- 删除 `QMessageBox.information(...)` — 避免每次确认都弹窗打断操作
- 新增 `self._clear_selection()` — 确认后自动清除当前框选，方便立即开始下一次框选

##### 3.2.2 修改 `_open_preview()` (L175-187)

**当前代码：**
```python
def _open_preview(self):
    row = self.table.currentRow()
    if row < 0:
        QMessageBox.warning(self, "提示", "请先选择要配置的提取规则行")
        return
    path, _ = QFileDialog.getOpenFileName(self, "选择 PDF 预览文件", "", "PDF 文件 (*.pdf)")
    if not path:
        return
    dlg = PdfPreviewDialog(path, self)
    dlg.coordinates_confirmed.connect(
        lambda x1, y1, x2, y2, page: self._fill_coords(row, x1, y1, x2, y2, page)
    )
    dlg.exec_()
```

**修改后：**
```python
def _open_preview(self):
    # 如果预览窗口已存在，直接提到最前
    if self._preview_dlg is not None and self._preview_dlg.isVisible():
        self._preview_dlg.raise_()
        self._preview_dlg.activateWindow()
        return

    path, _ = QFileDialog.getOpenFileName(self, "选择 PDF 预览文件", "", "PDF 文件 (*.pdf)")
    if not path:
        return
    self._preview_dlg = PdfPreviewDialog(path, self)

    def on_confirm(x1, y1, x2, y2, page):
        # 实时获取当前选中行（而非打开窗口时的固定行）
        current_row = self.table.currentRow()
        if current_row < 0:
            QMessageBox.warning(self, "提示", "请先在规则表中选择目标行")
            return
        self._fill_coords(current_row, x1, y1, x2, y2, page)

    self._preview_dlg.coordinates_confirmed.connect(on_confirm)
    self._preview_dlg.finished.connect(self._on_preview_closed)
    self._preview_dlg.show()  # 非模态显示，不阻塞规则表操作
```

##### 3.2.3 新增窗口关闭回调

```python
def _on_preview_closed(self):
    """PDF 预览窗口关闭时清理引用。"""
    self._preview_dlg = None
```

##### 3.2.4 确保点击「选择PDF预览并框选」时无需先选中行

原代码先检查 `row < 0` 并要求选中行。修改后允许先打开 PDF，选中行可在框选时再指定（由 `on_confirm` 中的 `current_row` 检查替代）。

### 技术要点

| 要点 | 说明 |
|---|---|
| 窗口复用 | `ConfigDialog` 持有 `PdfPreviewDialog` 引用，避免重复创建 |
| 非模态 `show()` | 用户可在预览窗口和规则表格之间自由切换 |
| 实时行绑定 | `on_confirm` 每次从 `self.table.currentRow()` 获取当前选中行 |
| 自动清框选 | 确认后调用 `_clear_selection()`，用户可立即开始下一次框选 |
| 资源释放 | 窗口 `closeEvent` 中关闭 `fitz` 文档句柄，防止内存泄漏 |
| `finished` 信号 | 监听窗口关闭，清理引用 |
