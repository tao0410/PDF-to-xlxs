# PDF信息提取与Excel生成工具 产品需求文档(PRD)
## 1. 产品概述
### 1.1 产品名称
PDF信息提取与Excel生成工具

### 1.2 产品定位
一款轻量级、纯本地运行的Windows桌面应用，专为需要从大量格式统一的PDF文档中提取结构化信息并整理成Excel表格的办公人员设计。

### 1.3 产品目标
开发一个能够在**Windows 7 SP1及以上系统完全离线运行**的工具，通过可视化框选配置提取规则，支持单文件和多文件两种处理模式，自动提取PDF指定位置的内容，经用户确认和编辑后，生成按编号统一排序的Excel文件，大幅提高信息整理效率，减少人工录入错误。

### 1.4 核心价值
- **零依赖部署**：单个exe文件，无需安装任何运行环境
- **可视化配置**：通过鼠标框选即可设置提取区域，无需手动输入坐标
- **双模式处理**：灵活支持单文件逐个确认和多文件批量确认
- **完全离线**：所有数据处理都在本地完成，不泄露任何敏感信息

## 2. 运行环境要求
| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 7 SP1 及以上版本（32位/64位） |
| 运行依赖 | 无需安装.NET Framework、Java等任何额外运行环境 |
| 网络要求 | 完全离线运行，不依赖任何网络连接 |
| 硬件要求 | 最低配置：2GB内存，1GHz处理器，100MB可用磁盘空间 |
| 兼容性 | 支持PDF 1.4及以上版本，兼容Microsoft Excel 2007及以上版本生成的.xlsx文件 |

## 3. 功能需求
### 3.1 主界面功能
#### 3.1.1 文件管理功能
- 点击"打开"按钮，弹出标准Windows文件选择对话框，默认只显示PDF文件(*.pdf)
- 支持同时选择多个PDF文件（按住Ctrl或Shift键多选）
- 支持从文件资源管理器拖拽PDF文件到主界面添加
- 显示已选择文件列表，包含：序号、文件名、文件大小、处理状态（待处理/处理中/已确认/已跳过）
- 支持移除单个已选择的文件
- 支持清空所有已选择的文件
- 自动检测并提示重复文件
- 显示已选择文件的总数、已处理数和待处理数

#### 3.1.2 处理控制功能
- "开始处理"按钮：点击后开始提取所有已选择的PDF文件内容
- 处理过程中显示整体进度条和当前正在处理的文件名
- 处理过程中可点击"取消"按钮终止操作
- 只有当所有文件都处理完成（已确认或已跳过）后，"生成Excel"按钮才可用

#### 3.1.3 总内容编辑功能
- 主界面下方显示总内容编辑表格，实时展示所有已确认的内容
- 表格列对应配置的提取区域，增加"来源文件"列
- 支持直接在表格中编辑任何单元格的内容
- 支持添加新的记录行
- 支持删除不需要的记录行
- 支持批量选择多行进行删除操作
- 显示总记录数

#### 3.1.4 配置管理功能
- 提供"配置提取规则"按钮，打开提取规则配置窗口
- 提供"加载配置"按钮，加载已保存的*.cfg配置文件
- 提供"保存配置"按钮，将当前配置保存为*.cfg文件

#### 3.1.5 Excel生成功能
- 点击"生成Excel"按钮，将总内容编辑表格中的所有记录按"编号"列升序排序
- 生成标准的.xlsx格式文件
- Excel文件包含与总内容编辑表格相同的列标题（包括"来源文件"列）
- 自动调整列宽以适应内容
- 为表头添加背景色和加粗效果
- 支持设置生成文件的保存路径和文件名
- 默认文件名格式："PDF信息汇总表_YYYYMMDD_HHMMSS.xlsx"
- 生成完成后弹出成功提示，提供"打开文件"和"打开文件夹"快捷按钮

### 3.2 核心处理逻辑（必须严格遵守）
#### 3.2.1 单文件处理模式
当用户只选择**1个**PDF文件时：
1. 点击"开始处理"按钮，提取该PDF文件的内容
2. 提取完成后立即弹出**单个文件确认窗口**
3. 用户检查并编辑提取的内容
4. 用户点击"确认"按钮，内容保存到总内容编辑表格
5. 用户点击"重新提取"按钮，使用相同配置重新提取该PDF文件
6. 用户点击"取消"按钮，不保存内容，返回主界面

#### 3.2.2 多文件处理模式
当用户选择**≥2个**PDF文件时：
1. 点击"开始处理"按钮，批量提取所有PDF文件的内容
2. 全部提取完成后弹出**统一确认窗口**，展示所有提取结果
3. 用户检查并编辑所有内容
4. 用户点击"全部确认"按钮，所有内容保存到总内容编辑表格
5. 用户点击"重新提取全部"按钮，使用相同配置重新提取所有PDF文件
6. 用户点击"取消"按钮，不保存任何内容，返回主界面

### 3.3 提取规则配置功能
#### 3.3.1 基础配置功能
- 支持配置多个提取区域，每个区域包含：
  - 区域名称（如"编号"、"名称"、"日期"、"金额"等）
  - 页面范围（如"第1页"、"第2-5页"、"所有页"）
  - 左上角X坐标
  - 左上角Y坐标
  - 右下角X坐标
  - 右下角Y坐标
  - 数据类型（文本/数字/日期）
- 支持添加新的提取区域
- 支持删除已有的提取区域
- 支持调整提取区域的顺序
- 提取规则可保存为*.cfg配置文件
- 支持加载已保存的配置文件
- 提供默认配置模板

#### 3.3.2 可视化框选功能（核心新增功能）
- 在配置窗口添加"选择PDF预览并框选"按钮
- 点击按钮弹出标准文件选择对话框，选择任意PDF文件用于预览
- 打开独立的PDF预览与框选窗口
- 支持PDF翻页功能（上一页/下一页）
- 支持PDF缩放功能（放大/缩小/适应窗口/实际大小）
- 用户可使用鼠标在PDF预览区域拖拽绘制矩形框
- 框选过程中实时显示鼠标坐标和框选区域坐标
- 框选完成后点击"确认坐标"按钮，自动将以下信息填充到当前**选中的提取规则行**：
  - 左上角X/Y坐标
  - 右下角X/Y坐标
  - 当前页码（填充到"页面范围"字段）
- 支持清除当前框选，重新绘制
- 关闭PDF预览窗口不影响已填写的配置内容
- 未选中任何提取规则行就点击框选按钮时，提示"请先选择要配置的提取规则行"

### 3.4 内容确认与编辑功能
#### 3.4.1 单个文件确认窗口
- 窗口标题显示当前处理的文件名
- 以表格形式展示该文件提取的所有内容
- 表格列对应配置的提取区域
- 高亮显示可能有问题的内容（如格式错误、内容为空、提取失败）
- 支持直接在表格中编辑任何单元格的内容
- 提供三个操作按钮：
  - "确认"：保存当前内容到总内容编辑表格，关闭确认窗口
  - "重新提取"：使用相同配置重新提取当前PDF文件
  - "取消"：不保存当前内容，关闭确认窗口

#### 3.4.2 统一确认窗口（多文件模式）
- 窗口标题显示"批量确认提取内容"
- 顶部显示处理结果统计："共处理X个文件，成功Y个，失败Z个，总记录数W条"
- 以表格形式展示所有PDF文件提取的全部内容
- 表格列对应配置的提取区域，增加"来源文件"列
- 高亮显示可能有问题的内容（如格式错误、内容为空、提取失败）
- 支持直接在表格中编辑任何单元格的内容
- 支持添加新的记录行
- 支持删除不需要的记录行
- 支持批量选择多行进行删除操作
- 提供三个操作按钮：
  - "全部确认"：保存表格中所有内容到总内容编辑表格，关闭确认窗口
  - "重新提取全部"：使用相同配置重新提取所有PDF文件
  - "取消"：不保存任何内容，关闭确认窗口

### 3.5 辅助功能
#### 3.5.1 日志功能
- 记录所有操作日志，包括文件添加、移除、提取、确认、生成等
- 详细记录每个PDF文件的处理时间和结果
- 记录错误和异常信息
- 日志文件保存在应用程序目录下的logs文件夹中
- 日志文件按日期命名，自动保留最近30天的日志

#### 3.5.2 异常处理
- 单个PDF提取失败时，弹出错误提示，用户可选择"跳过该文件"或"取消全部处理"
- 自动去除提取内容中的多余空格、换行符和特殊字符
- 对提取的数字和日期进行格式验证
- 选择非PDF文件时，弹出错误提示
- 打开损坏的PDF文件时，弹出错误提示
- 框选区域超出PDF页面范围时，自动修正为页面边界坐标
- 磁盘空间不足时，弹出错误提示
- 生成的Excel文件正在被其他程序打开时，弹出错误提示

## 5. 交互流程设计
### 5.1 完整使用流程
```
用户启动软件
    ↓
配置提取规则（首次使用）
    ↓
选择一个或多个PDF文件
    ↓
点击"开始处理"按钮
    ↓
┌─────────────────────┐
│ 选择文件数量 = 1?   │
└─────────┬───────────┘
          │
          ├─ 是 → 提取单个PDF → 弹出单个文件确认窗口 → 用户确认/编辑
          │
          └─ 否 → 批量提取所有PDF → 弹出统一确认窗口 → 用户确认/编辑
          │
          ↓
内容保存到主界面总内容编辑表格
    ↓
用户在主界面做最终调整
    ↓
点击"生成Excel"按钮
    ↓
生成按编号排序的Excel文件
    ↓
弹出成功提示，提供打开文件和文件夹选项
    ↓
流程结束
```

### 5.2 提取规则配置流程
```
用户点击"配置提取规则"按钮
    ↓
打开提取规则配置窗口
    ↓
用户添加/删除/修改提取区域
    ↓
用户点击"选择PDF预览并框选"按钮
    ↓
选择PDF文件，打开预览窗口
    ↓
用户翻页到需要提取的页面
    ↓
用户拖拽鼠标框选提取区域
    ↓
点击"确认坐标"按钮
    ↓
坐标和页码自动填充到选中的提取规则行
    ↓
重复上述步骤配置所有提取区域
    ↓
点击"保存"按钮保存配置
    ↓
关闭配置窗口
    ↓
流程结束
```

## 6. 非功能需求
### 6.1 性能要求
- 单个PDF文件提取时间不超过2秒
- 批量处理100个PDF文件的总时间不超过5分钟
- 应用程序启动时间不超过3秒
- 内存占用不超过500MB

### 6.2 可靠性要求
- 单个PDF提取失败不影响其他PDF文件的处理
- 应用程序崩溃后不会丢失已保存的配置文件
- 生成的Excel文件不会损坏，能够正常打开

### 6.3 易用性要求
- 所有功能都有明确的文字说明
- 操作流程符合Windows用户习惯
- 错误提示清晰易懂，能够指导用户解决问题
- 无需专业知识，普通办公人员5分钟内即可上手使用
